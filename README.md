# מחברת המאמן

אתר לניהול אימוני כדורסל: סרטוט תרגילים מונפשים, יומן אימונים, ספריית מסמכים ומשימות.
האתר סטטי לגמרי (HTML, CSS ו-JavaScript בלי שרת), ולכן רץ ישירות מ-GitHub Pages.

## מה יש בו

**תרגילים** — מגרש חצי או מלא, שחקני התקפה והגנה, מאמן, קונוסים וכדור. קווי ריצה, כדרור, מסירה וחסימה.
כל תרגיל בנוי משלבים: מזיזים את השחקנים בשלב הבא, והקווים שצוירו בשלב הקודם קובעים את המסלול באנימציה.
שליחה בשלוש דרכים: סרטון (MP4 בכרום ובספארי עדכניים), תמונה של שלב, וקישור לצפייה שמכיל את כל התרגיל.

**אימונים** — פרטים, מבנה עם זמנים (מתוך הספרייה או חלקים חופשיים), תמונות, סיכום, דירוגים
ובדיקת סדר וארגון של 9 סעיפים. כפתור "קבלת המלצות" שולח הכל ל-Claude ומחזיר ניתוח, אימון המשך
והרגלים לשיפור הסדר. "אימון המשך" פותח אימון חדש על בסיס הנוכחי.

**מסמכים** — העלאת PDF, Word, תמונות וטקסט, פתקים וקישורים. הטקסט מתוך PDF ו-Word נקרא אוטומטית,
כך שהחיפוש מוצא גם מילים מתוך המסמך.

**משימות** — הוספה מהירה, תחומים, עדיפות, תאריך יעד, משימות חוזרות (יומי, שבועי, חודשי), וקיבוץ לפי באיחור / היום / השבוע.

## איפה הנתונים

הכל נשמר בדפדפן של המכשיר (IndexedDB). שני מכשירים לא רואים זה את זה. לכן:
- בהגדרות יש **הורדת גיבוי** לקובץ אחד, ו**שחזור** ממנו במכשיר אחר.
- כדאי ללחוץ "בקשת אחסון קבוע" ולהוסיף את האתר למסך הבית בטלפון.

## התייעצות עם Claude

בלי הגדרה: האתר מכין שאלה מלאה, מעתיק אותה ופותח את claude.ai, ואת התשובה מדביקים בחזרה.
עם מפתח API (הגדרות): התשובה מגיעה ישר לאימון, כולל ניתוח התמונות. המפתח נשמר רק בדפדפן.

## פרסום ב-GitHub Pages

Settings → Pages → Source: Deploy from a branch → Branch: `main`, תיקייה `/ (root)` → Save.
אחרי דקה-שתיים האתר זמין בכתובת `https://<user>.github.io/<repo>/`.

## הרחבה בעתיד לכמה משתמשים

כל הגישה לנתונים עוברת דרך `js/db.js` (פונקציות `all / get / put / del / saveFile`).
כדי לעבור לענן עם התחברות (למשל Supabase או Firebase) מחליפים את הקובץ הזה בגרסה שמדברת עם השירות,
ושאר האתר נשאר כמו שהוא.
